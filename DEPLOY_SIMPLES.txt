Se aparecer erro após deploy:
  
  1. Ver o erro nos logs:
     Apps > caloriadev > Logs
  
  2. Voltar para versão anterior (ROLLBACK):
     
     No seu terminal:
     $ git revert HEAD
     $ git push origin main
     
     No DigitalOcean:
     - Aguardar novo deploy (5 minutos)
     - Status deve voltar para ✅ DEPLOYED
     - App deve funcionar como antes
  
  3. Investigar o problema:
     - Ler DEPLOYMENT_SEGURO.md
     - Ver secção Troubleshooting
     - Ou abrir issue no GitHub
